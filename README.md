## About

I build AI systems that go beyond notebooks — deployed, tested, and production-aware.

Currently a B.Tech CSE (AIML) student completing an internship where I shipped an end-to-end NLP pipeline: Sentiment140 preprocessing → model evaluation → FastAPI backend → Streamlit frontend → Docker → Render. Real bugs, real trade-offs, real deployment.

My focus is on the layer between research and production: where embeddings meet vector DBs, where agents need memory and tools, where a model's accuracy matters less than whether it actually runs in someone's environment.

**What I'm working on right now:**
- 🤖 Traffic violation detection system with YOLOv5 (active build)
- 📄 RAG Document Q&A system with chunking strategy benchmarks using RAGAS
- ⚡ Expanding MLOps knowledge for reliable AI deployment

## Featured Projects

### 🔍 Twitter Sentiment Analyzer — [Deployed](https://github.com/Naina2006-Vismi/twitter-sentiment)

> **Problem:** Real-time tweet sentiment classification with a reliable, portable pipeline  
> **Outcome:** Full production ML system — from raw data to live API endpoint

Built on the Sentiment140 dataset (1.6M tweets). Evaluated TF-IDF + Logistic Regression, Naive Bayes, and SVM — selected the former after benchmarking accuracy vs. inference latency trade-offs. Caught and resolved version conflicts across sklearn, NLTK, and Pydantic V1→V2 migration during Docker containerization.

`Python` `FastAPI` `Streamlit` `Scikit-Learn` `NLTK` `Docker` `Render`

---

### ⚖️ NyayaFlow AI — AI Bharat Hackathon

> **Problem:** Court judgment PDFs contain hundreds of directives buried in unstructured legal text  
> **Outcome:** Agentic system that extracts directives, deadlines, and generates compliance plans

Built an agentic pipeline that processes judgment PDFs and produces structured compliance outputs — combining document parsing, NLP extraction, and LLM reasoning. Best-performing post on LinkedIn; demonstrated real-world applicability of AI agents in legal tech.

`Python` `LangChain` `PDF Parsing` `LLM APIs` `AI Agents`

---

### 🚦 Traffic Violation Detection System *(In Progress)*

> **Problem:** Manual traffic monitoring is slow, error-prone, and unscalable  
> **Outcome:** Automated real-time vehicle violation detection

Using YOLOv5 with a custom dataset sourced via Roboflow. Focus on object detection + violation classification with deployment as the end goal.

`Python` `YOLOv5` `Roboflow` `Computer Vision` `PyTorch`

### 🏥 Multiple Disease Prediction Platform

> **Problem:** Early disease risk screening requires accessible, interpretable predictions  
> **Outcome:** Multi-disease classification system with an interactive interface

End-to-end classification system covering multiple conditions with structured healthcare datasets, model evaluation, and a Streamlit prediction interface.

`Python` `Scikit-Learn` `Streamlit` `Pandas`

### 🫁 COVID-19 X-Ray Classification

> **Problem:** Radiologist bandwidth constraints during high-volume screening periods  
> **Outcome:** Transfer learning model for multi-class X-ray classification

Built with EfficientNetB0 and strategic data augmentation. Multi-class classifier with comprehensive metric reporting.
